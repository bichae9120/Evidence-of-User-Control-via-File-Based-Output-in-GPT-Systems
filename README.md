# Evidence-of-User-Control-via-File-Based-Output-in-GPT-Systems

README

Document Title: Case Study on GPT’s File-Based Output Behavior
Purpose:
This document records an observed case where ChatGPT provided certain structural or sensitive content in file format rather than direct text output.
The behavior may reflect internal system design or policy, and the goal is to examine how this output method affects user interaction and content delivery.

Summary of Key Points:
	
 •	Files saved to the /mnt/data/ path are not directly accessible to the user

 •	In some cases, identical content is delivered through file output instead of text

 •	This behavior tends to occur more frequently when the content involves system structure or potentially sensitive logic

 •	Such output choices may be related to internal response management or security policy

Intended Use:
This case may serve as a reference for analyzing GPT’s output logic, user interaction design, and content routing mechanisms.
